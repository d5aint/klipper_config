# Voron 2.4r2 - 300mm

Klipper configuration for a 300×300×220 mm **Voron 2.4r2** (LDO kit), CoreXY, CAN toolhead.


⚠️ **Use at your own risk** ⚠️
- These are personal machine settings - steppers currents, PID/PA values, offsets, and macro behavior are tuned for *this* printer. 
- Copying onto a different machine without re-tuning can damage hardware.
